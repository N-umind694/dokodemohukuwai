# いつでもどこでも福笑い

スマートフォン縦画面向けの 3D 福笑いブラウザゲーム（制作中）。Three.js 製で、ビルド工程なしの静的ファイルだけで動く。

読み込んだ写真から顔のパーツ（眉・目・鼻・口）を切り出し、それを使って福笑いをする予定。写真は端末の中だけで処理し、どこにも送らない。

## 遊び方

- タイトル画面ではサンプルの顔（絵）で遊べる。画像を選ばずに「はじめる」を押すと、画像を選べば自分の顔で遊べることと、選ばなくても遊べることをポップアップで知らせる。
- 「画像をえらぶ」を押すと、画像の取り扱い（端末の外に送らない、など）を示すポップアップを出し、同意すると画像を選べる。画像を選ぶと、顔を見つけて眉・目・鼻・口を切り出し、切り出した跡を周りの肌の色で埋めた土台を作る。以後はその顔で遊ぶ。
- 写っている顔が複数あるときは、いちばん大きい顔を使う。顔が見つからなければ、その旨を表示する。
- 写真はこの端末の中だけで使い、どこにも送らない。

## 現状

- BGM: タイトル画面と結果画面は「正月の朝」（`assets/audio/bgm_title.mp3`）、プレイ中は「正月の激しい鼓動」（`assets/audio/bgm_play.mp3`）。どちらも受け取った音源から、曲名・作者名・作成記録・ジャケット画像のタグだけを外したもの（音のデータは同じ）。
- 完成演出では「正月の朝」を、曲がいちばん盛り上がる区間の頭（93.139 秒）から流し、約 153 BPM の拍にカットを合わせる（4 拍 / 4 拍 / 4 拍 / 1 拍×3 / 4 拍、着地の 3 拍後に称号）。カメラの揺れ・端末の振動・拍に合わせた画角の脈打ち・カットの切り替わりの閃光・色味の変化は使わず、カットの切り替わりは暗がりから静かに明けるように溶け込ませ、暖かい光をゆっくり漂わせる。カメラはゆっくり動き出してゆっくり止まる。結果画面ではその曲をそのまま流し続ける。区切りは `public/js/finale.js` の `MUSIC_OFFSET`・`BEAT`・`CUES`。
- 台詞の素材はまだ入っていない。
- 見た目は正月風（ロゴに合わせた赤・金・白、背景に金の青海波、タイトル画面に門松と梅）。
- 3D の背景は昭和の家の正月の和室（`public/js/room.js`）。畳・障子・襖・土壁・柱と長押、開けた障子の先に庭、床の間に「迎春」の掛け軸と鏡餅。土台は部屋の真ん中の座卓の上に置く。完成演出で土台を写真立てのように立てる場面では、座卓の代わりに赤い毛氈のひな壇に飾る。箱と板で組み、表面には `public/assets/room/` の素材写真（畳・木目・障子・土壁・竹の外柵・外壁・赤毛氈・ひな壇の木地・襖の布。各 512px の JPEG、合計約 350KB）を貼る。継ぎ目が出ないよう、畳は 1 畳ずつ向きを変えて敷き、天井は板ごとに描き分け、障子は格子の線の位置でつなぎ、土壁や布は明るさのムラを平らにしてから端をなじませて繰り返す。部屋の材質は光の計算をしない軽い描き方にしている。素材はページを開いたときに読み込む。

## 顔の切り出し（`public/js/faceAssets.js`）

1. 写真を長い辺 1600px までに縮めて読み、MediaPipe Face Landmarker で顔の点（478 か所）を見つける。
2. 顔の輪郭が土台（540×600）の真ん中に、高さの 6 割ほどで収まるように切り出す。
3. 眉・目・鼻・口の点を囲む形を少し広げ、縁をぼかして切り抜く。
4. 切り抜いた跡は、まわりの色を粗い解像度で集めて細かい解像度に戻す方法で、なめらかに埋める。

  style.css

## ローカルで動かす

```
npx http-server public -p 8080 -c-1 -a 127.0.0.1
```
